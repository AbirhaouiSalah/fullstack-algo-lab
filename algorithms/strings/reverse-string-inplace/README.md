# Reverse String Inplace

difficulty: Easy

## Problem Statement

Given an array of characters `chars`, reverse it **in-place** with `O(1)`
extra space.

Example:
```
Input:  ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

## Intuition

Two pointers starting at each end, swapping and moving inward until they
meet, cross, or coincide.
