# 3Sum

## Problem Statement

Given an integer array, return all unique triplets whose values sum to zero.

## Hints

- Hint 1: sort the array, fix one value, then search the remaining range with
  two pointers while skipping duplicate values.
- Hint 2: for each fixed value, find pairs using a set of complements.
