# Valid Palindrome

## Problem Statement

Determine whether a string is a palindrome after ignoring non-alphanumeric
characters and letter case.

## Hints

- Hint 1: normalize the input, then compare it with its reverse.
- Hint 2: compare from both ends while skipping punctuation and spaces.
