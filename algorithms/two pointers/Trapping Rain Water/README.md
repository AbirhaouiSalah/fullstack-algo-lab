# Trapping Rain Water

## Problem Statement

Given non-negative bar heights, return how much rain water can be trapped
between the bars after raining.

## Hints

- Hint 1: for every position, find the tallest wall on its left and right.
- Hint 2: use two pointers, processing the side with the smaller maximum wall.
