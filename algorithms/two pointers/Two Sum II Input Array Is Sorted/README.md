# Two Sum II: Input Array Is Sorted

## Problem Statement

Given a sorted integer array and a target, return the 1-based indices of the
two values whose sum equals the target. Exactly one solution exists.

## Hints

- Hint 1: compare the sum at the left and right ends and move one pointer.
- Hint 2: for each first value, binary-search for its complement.
