# Pattern Recognition Cheat Sheet

| Pattern | Signal in problem statement | Typical complexity |
|---|---|---|
| Two Pointers | Sorted array, pair/triplet sum | O(n) / O(n log n) |
| Sliding Window | Contiguous subarray/substring | O(n) |
| Fast/Slow Pointers | Linked list cycle detection | O(n) |
| Binary Search | Sorted or monotonic search space | O(log n) |
| BFS/DFS | Graph/tree traversal, shortest path (unweighted) | O(V+E) |
| Backtracking | "All combinations/permutations" | Exponential |
| Dynamic Programming | Optimal substructure, overlapping subproblems | O(n*m) typical |
| Greedy | Local optimum leads to global optimum | O(n log n) typical |
| Heap | "k largest/smallest", streaming median | O(n log k) |
