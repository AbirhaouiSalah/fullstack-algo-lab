# 15-Step Problem-Solving Protocol

1. Read the problem twice before writing anything.
2. Restate the problem in your own words.
3. Identify inputs, outputs, and constraints.
4. List edge cases explicitly.
5. Work through 2-3 examples by hand.
6. Identify the naive/brute-force approach.
7. State its time and space complexity.
8. Look for a pattern (two pointers, sliding window, DP, etc.).
9. Sketch the optimized approach on paper/whiteboard.
10. State the optimized time and space complexity.
11. Implement the TypeScript solution.
12. Implement the Python solution.
13. Write Vitest tests covering edge cases.
14. Update complexity.md with the tradeoff analysis.
15. Log any mistakes made along the way in mistakes.md.
